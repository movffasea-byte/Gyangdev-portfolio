# Professional Portfolio

A static, responsive portfolio for Gaba Abraham Gyang.

## Files

- `index.html` — page content and metadata
- `P-P.css` — responsive styling
- `script/P-P.js` — mobile-navigation behavior

## Publish on GitHub Pages

1. Replace the matching files in the `jaifore-media` repository with this folder's contents.
2. Keep the `script` folder intact.
3. Commit and push to the `main` branch.
4. In GitHub, open **Settings → Pages** and confirm deployment from the `main` branch.

Before publishing, add a real LinkedIn URL and replace project descriptions or claims with any measurable results you can verify.
